# FONBET // AI PREDICTOR

Страница для телефона и компьютера: линия и лайв Фонбета, анализ матчей с помощью ИИ и математической модели, экспрессы и автоматическое отслеживание ваших ставок. Всё работает в одном файле `index.html` прямо в браузере, сервер не нужен.

Открыть: `https://99999cent-bit.github.io/fonbet-dashboard-/` (после обновления добавьте в конец `?v=` и любое число, чтобы браузер не показал старую версию).

## Быстрый старт
1. Откройте ⚙️ → «Искусственный интеллект и ключи».
2. Выберите ИИ (Gemini, DeepSeek, Qwen или Claude) и вставьте ключ в его блок. Нажмите «🔑 Проверить ключи».
3. Выберите модель в списке на главном экране.
4. Нажмите на матч → «⚡ AI Анализ матча».

## Источники данных
- **Линия и лайв** — напрямую с серверов Фонбета (или через свой сервер, адрес в ⚙️).
- **Итоги матчей** — раздел «Результаты» Фонбета (`results/v2/getByDate`): ставки проставляются сами, даже если страница была закрыта.
- **Архив итогов** — за 14–90 дней (⚙️ → «Архив итогов Фонбета»). По номерам команд считаются форма, голы дома и в гостях, таймы, первый гол, угловые и карточки (где есть), отдых, рейтинг Эло, очные встречи.
- **Движение линии** — первый увиденный коэффициент и коэффициент перед стартом.
- **API-Football** (необязательно, бесплатно 100 запросов в день) — составы, травмы, стадион, судья, сравнение команд для футбола.
- **Погода у стадиона** — Open-Meteo (бесплатно, без ключа).
- **Разведка в интернете** — ИИ с поиском (Gemini, Qwen, Claude) ищет составы, травмы, мотивацию, календарь, судью.

## Режимы анализа (⚙️ → «Анализ матча и расход токенов»)
| Режим | Что делает | Запросы к ИИ |
|---|---|---|
| 📐 Только математика | модель по коэффициентам и архиву | 0 |
| ⚡ Быстрый | аналитик без поиска | 1 |
| 🧠 Глубокий | разведчик с поиском + аналитик | 2 |
| 🏆 Максимум | разведчик + аналитик дважды + критик | 4–5 |

## Как считается вероятность
1. **Рынок без маржи** — коэффициенты Фонбета, очищенные от маржи.
2. **Модель** — футбол и хоккей: Пуассон (подгонка под коэффициенты + статистика архива, в лайве — по оставшемуся времени); баскетбол: нормальное распределение тотала и разницы очков; теннис, настольный теннис и другие два исхода: рейтинг Эло.
3. **Поправки ИИ** — каждая поправка привязана к факту (например, «−5 п.п.: не играет основной вратарь»).
4. **Итог** = модель + доля поправки ИИ. Долю программа подбирает сама по прошлым итогам (по умолчанию 50%).
5. **Выгода** = вероятность × коэффициент − 1. Разумная ставка — четверть критерия Келли, не больше 3% банка.

Нажмите на ставку, чтобы увидеть весь расчёт по шагам, составы, отсутствующих игроков, источники.

## Ключи
- У каждого ИИ свой блок ключей: нажмите на название, чтобы развернуть или свернуть. «➕ Добавить ключ» добавляет поле, «✕» удаляет.
- Если на ключе закончился лимит или баланс, программа сама переходит к следующему ключу и запоминает рабочий.
- Галочка «пробовать другие ИИ» включает запасной ИИ, если у выбранного кончились все ключи.
- Лимиты Gemini считаются на проект Google: ключи из разных проектов дают больше бесплатных запросов.
- Ключи хранятся только в вашем браузере. Не публикуйте их и не отправляйте в чаты.

## Другое
- **Экспресс** (3–30 событий): шанс пройти целиком по модели, честный коэффициент против коэффициента Фонбета.
- **Лучшие ставки** из лайва и из будущих матчей на 24 часа: модель отбирает кандидатов, ИИ выбирает 3 (в режиме «Только математика» — без ИИ).
- **Перепроверка составов** за 15–70 минут до начала по вашим подтверждённым ставкам (режимы «Глубокий» и «Максимум»).
- **Уведомления** об итогах ваших ставок и изменениях составов (⚙️ → «Слежение за матчами»). Для Android используется `sw.js`.
- **Качество аналитика** (вкладка «Анализ матча»): точность по видам спорта и рынкам, доходность, «цена» (насколько ваш коэффициент лучше коэффициента перед стартом).
- **Перенос на другое устройство**: ⚙️ → «Сохранить всё в файл» / «Загрузить из файла» (ставки объединяются).

## Важно
Модель и ИИ не знают исходов. Это инструмент для честной оценки вероятностей и отказа от плохих ставок, а не гарантия выигрыша.

## Файлы
- `index.html` — приложение целиком.
- `sw.js` — служебный файл для уведомлений на Android (ничего не кэширует).
- `server.js`, `package.json` — необязательный сервер-посредник (нужен, только если Фонбет не пускает прямые запросы со страницы).
